# Registration redesign

References: https://linear.app/signup and https://app.notion.com/signup
Use their focused email-first hierarchy as inspiration, not their branding or unsupported social sign-in controls.
The Smart Merchant design uses a sage editorial panel, existing shop illustration,
teal primary CTA, labeled inputs and a compact three-step progress indicator.
No decorative arrows in authentication CTAs. OTP is revealed only after a successful
request. Existing password requirements, verification endpoints and tenant creation
remain unchanged. No real account is created during visual acceptance testing.
