- The ecommendation_industry selector is a reference-profile configuration. It is not proof that a separately trained industry propensity model exists.
- The API explicitly reports no separately trained purchase-probability model with labels, inference contract, and evaluation evidence. It distinguishes the optional LightFM candidate ranker from propensity prediction.
- No training was run, and no model availability/quality was inferred from code presence alone.
